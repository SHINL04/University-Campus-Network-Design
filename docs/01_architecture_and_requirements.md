# Phase 1: Architecture and Requirements

## Business Requirements
The university requires a network design that separates different user groups for security while maintaining high availability.

## User Segments
1. Administration (Highly Secure)
2. Faculty/Teachers (Internal Resources & Internet)
3. Students (Internet Only)
4. IoT/Infrastructure (Cameras, Smart Boards)

## Network Design Choice
* **Topology:** Two-Tier Collapsed Core Design.
* **Reasoning:** Cost-effective for a mini-campus while offering full redundancy at the core level.
