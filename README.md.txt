# University Mini-Campus Network Design & Implementation

## 📌 Project Overview
An enterprise-grade, highly secure, and scalable multi-tier network architecture designed for a modern university campus environment. This project demonstrates advanced layer 2 and layer 3 networking concepts, strict security segmentation, and professional documentation standards.

## 🏗️ Architecture Features
*   **Three-Tier Hierarchical Design:** Core, Distribution, and Access layers.
*   **Logical Segmentation:** Advanced VLAN design separating Academics, Administration, IoT, and Public Guest traffic.
*   **Inter-VLAN Routing & Security:** Stateful traffic filtering using Access Control Lists (ACLs).
*   **IP Management:** Optimized VLSM (Variable Length Subnet Masking) design to eliminate address wasting.

## 📁 Repository Structure
*   `docs/`: Network design blueprints, IP schemas, and engineering journals.
*   `topology/`: Network architecture diagrams (Draw.io and PNG formats).
*   `config/`: Production-ready device configuration scripts organized by hardware tier.
